# Original notebooks

The original notebooks are intentionally not duplicated in this repository archive. They remain the experimental record of the PFE. The Python package was refactored from the following sequence:

1. `22_extract360_select_preannotate` → extraction, diversified selection and CVAT pre-annotation.
2. `23_final_training_mask2former` → CVAT conversion, grouped split and Mask2Former fine tuning/evaluation.
3. `24_bfms_materials_1041` → BFMS inference on the complete route.
4. `25_fusion_v5_albedo_fixe_2` → semantic/material gating, RAL match and fixed albedo.
5. `29_indicateurs_svf_gvi_permeabilite_version_8` → SVF, GVI, permeability and visible built fraction.
6. `30_correlation_v8_visualisation_complete` → Comfy'Pack processing, Tmrt/UTCI, inertia and statistics.
